## 为什么CN2 GIA这件事很重要

对于国内用户来说，访问海外服务器最头疼的就是"晚高峰体验断崖式下降"。普通国际线路因为共享拥堵，高峰期延迟动辄翻倍，甚至直接丢包。

CN2 GIA（Global Internet Access）是中国电信推出的顶级直连线路，有独立的出口路由，不走公共拥挤节点，国内大多数地区访问香港节点可以稳定在30–50ms，即使晚高峰也不会明显劣化。衡天云全系产品标配这条线路，这是它区别于很多低价竞品的核心优势。

## 产品线概览：云服务器 vs 物理服务器

衡天云产品分两大类：**云服务器（VPS）** 和 **物理服务器（独立服务器）**，另外还有轻量云、高防服务器、站群服务器等细分品类。

云服务器基于自研KVM+OVS平台，支持Linux和Windows系统，配有国产智简魔方控制面板，重启、监控、重装系统都可以自助操作，新手也能上手。

物理服务器（独享机器）适合对性能和稳定性要求更高的企业用户，香港、日本、美国均有现机，官方承诺定制机6小时内完成交付。
